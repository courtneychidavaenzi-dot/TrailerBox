# Trailer Box Movie and anime trailer search
Live website for discovering real-time movies and anime trailers
# features
Real-time searching using TDMB API
Debounced search for performance optimization
React Router navigation
YouTube embeds for trailer playback
Responsive design- works on mobile & desktop
# Tech Stack
React SPA
TMDB API
React Router
YouTube Embed API
# How to run
npm install
npm start
